Karakeep MCP server (@karakeep/mcp 0.33.0, with @karakeep/sdk 0.33.0)

The Omni image includes the unmodified npm packages @karakeep/mcp and
@karakeep/sdk, version 0.33.0, in /app/mcp-stdio/node_modules. They run as a
separate program that Omni's MCP gateway starts and talks to over standard
input and output; Omni does not link to or modify them.
